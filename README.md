# Сладкая искра

Три в ряд для MAX и браузера: поле 8×8, 100 уровней в 10 главах, конфеты, кристаллы и блоки, каскады, звёзды, подсказки и звуки.

Играть: https://xz38666.github.io/sweet-spark-max/

Все уровни доступны сразу. Настройки и звёзды сохраняются в браузере. Для подключения к MAX укажите опубликованный HTTPS-адрес в настройках мини-приложения вашего бота.

В этом репозитории находятся все исходники статической игры. Сборка и зависимости не нужны. GitHub Pages публикует ветку main, каталог /(root).

Для локального просмотра запустите любой статический HTTP-сервер в этой папке, например `python -m http.server 4173`, и откройте http://localhost:4173.
